
Pregunta 6 - Gramática y ambigüedad

La gramática original presenta ambigüedad porque una
misma expresión puede interpretarse de diferentes
maneras. Esto ocurre cuando no se establece una
precedencia clara entre los operadores && y ||.

Por ejemplo, la expresión:

rmse < 5 || auc > 1 && latencia < 200

Puede interpretarse de dos formas:

1. (rmse < 5 || auc > 1) && latencia < 200

2. rmse < 5 || (auc > 1 && latencia < 200)

Si utilizamos estos valores:

rmse = 4
auc = 0.9
latencia = 250

La primera interpretación devuelve false,
mientras que la segunda devuelve true.

Esto demuestra que la ambigüedad puede cambiar
el resultado de una evaluación.

Gramática corregida:

expr ::= disyuncion

disyuncion ::= disyuncion '||' conjuncion
             | conjuncion

conjuncion ::= conjuncion '&&' primario
             | primario

primario ::= comparacion
           | '(' expr ')'

comparacion ::= nombre op numero

op ::= '<' | '>'

nombre ::= [a-z]+

numero ::= [0-9]+ ('.' [0-9]+)?

Con esta gramática, el operador && tiene mayor
precedencia que ||. Además, ambos operadores
se agrupan de izquierda a derecha.

De esta manera, cada expresión tiene una
interpretación definida y se evita que el
programa evalúe una condición de forma
diferente a la esperada.

Considero que este problema es importante
porque una interpretación incorrecta puede
provocar decisiones equivocadas en un sistema,
incluso cuando el programa no presenta errores
visibles.
