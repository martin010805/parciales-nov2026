

# Parcial 1 - Construcción de Software

**Estudiante:** Martin Eduardo Cristancho Salazar  
**Programa:** Ingeniería de Software

## Descripción

En este repositorio se encuentra el desarrollo del Parcial 1 de Construcción de Software. Incluye las respuestas a las preguntas, sus respectivas explicaciones y los archivos de código utilizados para resolver los ejercicios.

## Archivos del parcial

- `parcial1/Parcial1_Construccion_de_Software.pdf`: documento con las respuestas y explicaciones de las preguntas.
- `parcial1/src/pregunta2-ventana.ts`: corrección de la clase VentanaDeMetricas.
- `parcial1/src/pregunta3-promocion.ts`: función de promoción y pruebas de funcionamiento.
- `parcial1/src/pregunta4-igualdad.ts`: solución al problema de igualdad entre objetos.
- `parcial1/src/pregunta5-concurrencia.ts`: propuesta para controlar las promociones mediante transacciones.
- `parcial1/src/pregunta6-gramatica.txt`: análisis de la ambigüedad y propuesta de gramática corregida.

## Notas

La pregunta 1 está desarrollada directamente en el PDF, ya que no requiere código.

Los ejercicios de programación están escritos en TypeScript. En la pregunta 5 se presenta una propuesta para manejar la concurrencia, pero no se incluye una conexión real a una base de datos.

Los archivos están organizados por preguntas para facilitar su revisión.
