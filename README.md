En este repositorio se encuentra el desarrollo del primer parcial de Construcción de Software. Incluye las respuestas a las preguntas, las explicaciones correspondientes y los archivos de código utilizados para resolver los ejercicios.

## Archivos del parcial

- `parcial1/Parcial1_Construccion_de_Software.pdf`: desarrollo completo de las preguntas y sus explicaciones.
- `parcial1/src/pregunta2-ventana.ts`: corrección de la clase VentanaDeMetricas.
- `parcial1/src/pregunta3-promocion.ts`: función de promoción y pruebas de funcionamiento.
- `parcial1/src/pregunta4-igualdad.ts`: solución al problema de igualdad entre objetos.
- `parcial1/src/pregunta5-concurrencia.ts`: propuesta para controlar las promociones mediante transacciones.
- `parcial1/src/pregunta6-gramatica.txt`: análisis de la ambigüedad y gramática corregida.

## Notas

La pregunta 1 está desarrollada directamente en el PDF, ya que no necesita un archivo de programación.

Los ejercicios están escritos en TypeScript. En la pregunta 5 se presenta una solución propuesta para manejar la concurrencia, pero no se incluye una conexión a una base de datos.

El contenido está organizado por preguntas para facilitar su revisión.
